What each of them claims

Every line of every annotated crate is claimed, and the coverage gate fails the build over one unclaimed line, one overlap, or one range left behind by a version bump. There are two annotated crates and therefore two figures above; there is no third figure combining them, because 21,012 lines is not a promise anyone made.

A crate is claimed file by file. A file named as complete may never develop a hole — that is a build failure — and a file nobody has begun is reported at zero rather than quietly left out of the denominator.

Borrowed vocabulary is quoted, pinned, and named as borrowed.
