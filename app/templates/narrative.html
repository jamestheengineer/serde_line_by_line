What this track claims

A path, not a promise. This track picks one route through {{ derive_lines }} lines of serde_derive and follows it; it has never said it visits all of them, and it still does not. What changed is underneath it: serde_derive is now an annotated crate being claimed file by file, so where this walk stops on finished ground it links to the annotation there rather than explaining the same lines twice. The percentage belongs to that track. This one has an order.

What is checked is everything a reader could catch. Every line range resolves in a tree pinned by checksum. No step leans on one that comes later. A step standing on a file the reference track has finished must land inside an annotation and say which — and once that file is declared complete, the build fails if it does not. And every claim about generated code is sliced out of a real expansion at build time — if serde_derive stopped emitting it, this page would not build.
