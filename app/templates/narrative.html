What this track claims

Nothing exhaustive. The reference track claims every line of serde_core and a gate fails the build if one goes unclaimed. serde_derive is {{ derive_lines }} lines and is walked, not claimed: this track goes where the story goes, and no file of it is ever declared complete. A coverage percentage over a walk would be a lie told in a number.

What is checked is everything a reader could catch. Every line range resolves in a tree pinned by checksum. No step leans on one that comes later. Where the walk crosses into serde_core it must land inside an annotation the reference track already wrote, and it links there rather than explaining the same lines twice. And every claim about generated code is sliced out of a real expansion at build time — if serde_derive stopped emitting it, this page would not build.
