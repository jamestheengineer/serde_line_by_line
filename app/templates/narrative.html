What this track claims

A path, not a promise. This track picks one route through {{ walk.source_lines }} lines of {{ walk.crate_name }} and follows it; it has never said it visits all of them, and it still does not. Where it stops on ground the reference track has finished, it links to the annotation there rather than explaining the same lines twice. A percentage belongs to that track. This one has an order. {%- if !walk.annotated %} Most of its ground is not that, though: {{ walk.crate_name }} is pinned to be walked and never claimed, so on {{ walk.steps - walk.crossings }} of its {{ walk.steps }} stops the explanation here is the only one this site has. {%- endif %}

What is checked is everything a reader could catch. Every line range resolves in a tree pinned by checksum. No step leans on one that comes later. A step standing on a file the reference track has finished must land inside an annotation and say which — and once that file is declared complete, the build fails if it does not. {%- if walk.emitted > 0 %} And every claim about generated code is sliced out of a real expansion at build time — if serde_derive stopped emitting it, this page would not build. {%- endif %} {%- if walk.produced > 0 %} And every claim about what {{ walk.crate_name }} produces — {{ walk.produced }} of them — is located in the output of a real run of {{ walk.version }}, the same output the browser’s wasm is checked to print.
